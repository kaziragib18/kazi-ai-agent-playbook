# B14. Rules for improving this guide


Add an item only if it is checkable by a command or a short read, has a level, and a tag. Remove or reframe advice that is wrong for modern platforms (examples already removed: "force TLS 1.3", "memoize everything", "run Redis/load balancer/PgBouncer" on serverless). Anything legal is a draft for a lawyer, not legal advice.
